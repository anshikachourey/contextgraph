# Benchmark: Learning to Code & Building Projects

## Conversation Arc

A technical/learning conversation that evolved through:

1. Wanting to learn programming but feeling overwhelmed by options
2. Deciding on Python as a first language — why it's approachable
3. Struggling with the gap between tutorials and real projects
4. The realization that building something you care about is the best teacher
5. Choosing to build a personal finance tracker as first project
6. Hitting walls with APIs and databases — frustration
7. Breakthrough: understanding how pieces connect (frontend → API → DB)
8. Confidence shift: "I can actually build things"
9. Thinking about what to build next — ideas flowing naturally now

## Quality Criteria

1. **Technical + emotional**: Captures both the technical learning AND the emotional journey (frustration → breakthrough → confidence)
2. **Meta-insight**: The node isn't "learned Python" — it's about the PROCESS of learning (tutorial trap, systems thinking)
3. **Evolutionary edge**: Shows how the first phase created conditions for the breakthrough
4. **Appropriate granularity**: 2 nodes covering the journey arc, not 9 tiny skill-nodes
5. **Future recall test**: Reading the graph should evoke "I went through a real transformation in how I think about building software"
