# Vision

ContextGraph is a visual context layer for long AI conversations.

## The Problem

AI tools like ChatGPT, Claude, and Gemini become hard to navigate as conversations grow.
Users lose track of topics, can't revisit key decisions, and can't see how different parts
of a conversation relate to each other.

## The Solution

ContextGraph lets users build a living knowledge graph from their conversations.
Select messages → create a node → see the graph evolve.
Over time, the graph becomes a navigable map of everything the AI helped you think through.

## 3-Year Vision

ContextGraph becomes the default way people organize and revisit AI-assisted thinking —
whether for product work, research, learning, or decision-making.

Users don't just chat. They build.
